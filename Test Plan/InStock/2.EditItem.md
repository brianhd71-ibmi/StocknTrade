# Test Case: Verify Edit Item Category Functionality

## Prerequisites & Setup
* Access to the **IBM i** environment.
* Valid user credentials with permissions to access the **mstock** menu.
* A pre-existing item named `Test Item Add` available in the system.

## Test Steps & Expected Results

| Step | Action | Expected Result |
| :--- | :--- | :--- |
| **Step 1** | **Login** to IBM i and open the mstock menu using command `{go mstock}`. | The **mstock menu** opens successfully. |
| **Step 2** | **Select** the option for **The Catalog…** to open the application. | The Catalog application opens. |
| **Step 3** | **Tab down** to the item created in the previous test (`Test Item Add`) and **key a 2** next to it. |  |
| **Step 4** | **Press** `Enter`. | The **EDIT ITEM ** window opens. |
| **Step 5** | **Change** the description field from `Test Item Add` to `Test Item Edited`. |  |
| **Step 6** | **Change** the rest of the fields incrementing the values by 1. |  | 
| **Step 7** | **Press** `Enter` then `F5=Save` to save the edited Item. | The window closes and saves the modified data. |
| **Step 8** | **Observe** the grid.  | `Test Item Edited` should be in the grid with the correct information displaying. 
| **Step 9** | **Tab down** and place a `1` on the Test Item 1 row. |  A window should open with no editing capabilities. All the data saved when the item was edited should be correct. 
| **Step 10** | **Press** `F12=Cancel` or `Enter` to return to the main display.
