# Test Case: Verify Add Item Functionality and Number Increment

## Prerequisites & Setup
* Access to the **IBM i** environment.
* Valid user credentials with permissions to access the **mstock** menu.
* Categories and Origins must exist for lookups

## Test Steps & Expected Results

| Step | Action | Expected Result |
| :--- | :--- | :--- |
| **Step 1** | **Login** to IBM i and open the mstock menu using command `{go mstock}`. | The **mstock menu** opens successfully. |
| **Step 2** | **Select** the option for **InStock…** to open the application. | The Catalog application opens. |
| **Step 3** | **Select** `F6=Add New`. | A window opens with the title **ADD ITEM**. Note the item number|
| **Step 4** | *Optional*  `F12=Cancel` | Returns to the main display. Repeating `F6=Add New` opens the window again with the **same** item number noted previously.
| **Step 5** | **Fill out** the descrtiption field with `Test Item Add`
| **Step 6** | **Fill out** the rest of the fields using prompts if necessary. Press Enter to set the fields, and F5 to save. | Window closes and returns to main display.
| **Step 7** | **Observe** the grid.  | `Test Item Add` should be in the grid with the correct information displaying. 
| **Step 8** | **Tab down** and place a `1` on the Test Item 1 row. |  A window should open with no editing capabilities. All the data saved when the item was created should be correct. 
| **Step 9** | **Press** `F12=Cancel` or `Enter` to return to the main display.
