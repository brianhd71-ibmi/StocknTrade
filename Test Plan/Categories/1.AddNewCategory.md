# Test Case: Verify Add Item Category Functionality and Number Increment

## Prerequisites & Setup
* Access to the **IBM i** environment.
* Valid user credentials with permissions to access the **mstock** menu.

## Test Steps & Expected Results

| Step | Action | Expected Result |
| :--- | :--- | :--- |
| **Step 1** | **Login** to IBM i and open the mstock menu using command `{go mstock}`. | The **mstock menu** opens successfully. |
| **Step 2** | **Select** the option for **The Catalog…** to open the application. | The Catalog application opens. |
| **Step 3** | **Select** `F6=Add New`. | A window opens with the title **ADD/EDIT ITEM CATEGORY**. |
| **Step 4** | *(Optional)* **Select** `F12` to cancel the process. | The process is cancelled. **No new category** is created. *(Note the current category number for the next step).* |
| **Step 5** | **Select** `F6` again. | The window opens displaying the **same category number** noted in Step 4. The number **must not** increment. |
| **Step 6** | **Type** a new category name (e.g., `Test Add`) into the **Description** field. | The text is entered correctly into the field. |
| **Step 7** | **Press** `Enter` to save the new category. | The window closes, saving the data. |
| **Step 8** | **Verify** the grid for the newly created category. | The new category (`Test Add`) is successfully displayed in the grid. |
