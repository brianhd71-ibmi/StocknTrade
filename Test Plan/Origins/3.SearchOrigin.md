# Test Case: Verify Search Functionality

## Prerequisites & Setup
* Ensure there are at least **3 or more origins** created in the list.

## Test Steps & Expected Results

| Step / Element | Action / Condition | Expected Result |
| :--- | :--- | :--- |
| **Step 1** | Login to IBM i and open the `mstock` menu using command: `{go mstock}` | `mstock` menu opens successfully. |
| **Step 2** | Select the option for *Made In…* to open the application. | Made In application opens. |
| **Step 3** | Key in `T` in the search bar. | All origins starting with **T** display in alphabetical order. |
| **Step 4** | Key in `test` in the search bar. | All origins starting with **Test** display. |
| **Step 5** | Key in `test edited` in the search bar. | Only **Test Edited** entry{ies} display. |
