# Test Case: Verify Edit Item Origin Functionality

## Prerequisites & Setup
* Access to the **IBM i** environment.
* Valid user credentials with permissions to access the **mstock** menu.
* A pre-existing item Origin named `Test Add` available in the system.

## Test Steps & Expected Results

| Step | Action | Expected Result |
| :--- | :--- | :--- |
| **Step 1** | **Login** to IBM i and open the mstock menu using command `{go mstock}`. | The **mstock menu** opens successfully. |
| **Step 2** | **Select** the option for **Made In…** to open the application. | Made In application opens. |
| **Step 3** | **Tab down** to the origin created in the previous test (`Test Add`) and **key a 2** next to it. | The selection value `2` is entered next to the `Test Add` origin. |
| **Step 4** | **Press** `Enter`. | The **ADD/EDIT ITEM ORIGIN** window opens. |
| **Step 5** | **Change** the description field from `Test Add` to `Test Edited`. | The text is successfully updated in the field. |
| **Step 6** | **Press** `Enter` to save the edited origin. | The window closes and saves the modified data. |
| **Step 7** | **Verify** the item origin in the main grid. | The origin successfully displays as **Test Edited** in the grid. |
