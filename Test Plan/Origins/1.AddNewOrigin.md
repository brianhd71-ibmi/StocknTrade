# Test Case: Verify Add Item Origin Functionality and Number Increment

## Prerequisites & Setup
* Access to the **IBM i** environment.
* Valid user credentials with permissions to access the **mstock** menu.

## Test Steps & Expected Results

| Step | Action | Expected Result |
| :--- | :--- | :--- |
| **1** | **Login** to IBM i and open the mstock menu using command `{go mstock}`. | The **mstock menu** opens successfully. |
| **2** | **Select** the option for **Made In…** to open the application. | Made In application opens. |
| **3** | **Select** `F6=Add New`. | A window opens with the title **ADD/EDIT ITEM ORIGIN**. |
| **4** | *(Optional)* **Select** `F12` to cancel the process. | The process is cancelled. **No new origin** is created. *(Note the current origin number for the next step).* |
| **5** | **Select** `F6` again. | The window opens displaying the **same origin number** noted in Step 4. The number **must not** increment. |
| **6** | **Type** a new origin name (e.g., `Test Add`) into the **Description** field. | The text is entered correctly into the field. |
| **7** | **Press** `Enter` to save the new origin. | The window closes, saving the data. |
| **8** | **Verify** the grid for the newly created origin. | The new origin (`Test Add`) is successfully displayed in the grid. |
