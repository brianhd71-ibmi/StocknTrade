# Test Case: Verify Lookup Functionality

## Prerequisites & Setup
* Ensure there are at least **3 or more categories** created in the Application, "Made In...".

## Test Steps & Expected Results

| Step / Element | Action / Condition | Expected Result |
| :--- | :--- | :--- |
| **Step 1** | Login to IBM i and open the `mstock` menu using command: `{go mstock}` | `mstock` menu opens successfully. |
| **Step 2** | Select the option for *InStock* to open the application. | InStock application opens. |
| **Step 3** |  **Select** `F6=Add New`. | A window opens with the title **Add Item**. | 
| **Step 4** | Key in `0000` into the **Origin** field | A window opens with a list of at least 3 categories entitled: **CATEGORY LOOKUP** |
| **Step 5** | Key in `test edited` (*Or the name of one of the entries*) in the search bar. | Only **Test Edited** entry{ies} display. |
| **Step 6** | Tab down to the row **Test Edited** and place a 1 in the option field | Lookup window closes and returns the category displayed in the field|
| **Step 7** | Key in a random number that does not match any in the list | Lookup window opens again *Note one of the existing numbers |
| **Step 8** | **Select** F12 to close the window then **Key In** the number noted in the last step| No window opens. The matching origin is retrieved. |
